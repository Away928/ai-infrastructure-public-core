# Investment Research | 方法与投资判断

**先判断任务深度，再选择分析方法。** 已有信息或单一指标问题直接回答；只有完整投资假设、模型或组合决策才使用较深工作流。不要为普通问题自动创建 DCF、投资备忘录、回测或研究报告。

## 三种研究方法（按任务选，不串联成固定阶段）

- **Fundamental｜基本面**：业务与分部、盈利质量、竞争结构、管理层、资本配置、驱动因素、风险。只有估值任务才建立财务预测、DCF 或相对估值，并列明 FCF、CAPEX、营运资本、WACC、终值和敏感性。原始财报/公告与模型解释分离。
- **Quantitative / Systematic｜量化**：构建可检验的特征、信号、回测与组合规则。明确研究宇宙、数据可得时点、幸存者偏差、前视/泄漏、交易费用、滑点、换手、样本外验证、统计不确定性及与基准比较。单一 RSI/MA 不等于已验证的投资策略。
- **Quantamental｜基本面×量化**：把财报、文本、基本面事件转换为有时间戳的结构化因子；再按 Quantitative 标准验证增量预测价值。LLM 提取或观点生成属于研究输入，不等于可交易信号，不应与真实 alpha 混淆。

## 最短执行路径

1. 明确用户要的是事实核对、解释、单项分析、可复现模型，还是投资决策；只做相应层级。
2. 数据从已有可信来源、官方披露及当前 Agent 能力获取；需要专项抓取时可调用 **01 Information Acquisition**，不在本 Skill 新建检索层或重复采集。标清观测时间、财报期、币种、复权、口径与链接。
3. 只调用**一个**适合的分析方法；必要时交叉验证关键事实而不是重复搭建流程。数据缺失需报告缺口，不虚构收益、WACC、定价、预测、报价或引文。
4. 输出：结论、支持与反对证据、核心假设、风险和适用边界；若为真正投资建议，补充情景、下行风险、催化剂和足以推翻论点的证据；无需强制产出完整 memo。

**财报口径核对**：`get_stock_financial_abstract` 的 `total_operating_revenue` 对应财报合并利润表的**营业总收入**，不必然等于首页“营业收入”；金融子公司可产生利息收入等差额。FinQ 返回的数值可能是 `"514.43亿"`、`"10.67%"` 这样的**带单位字符串**，不能当作元直接运算。核对时必须同一报告期、合并口径、币种、单位与指标定义；先核对官方披露再使用第三方汇总值。尤其将归母净利润与合并净利润分开，不把报告期累计数误作单季度数。

**FinQ4Cn 定位**：仅在需要中国 A 股专业数据且当前 Agent 的数据能力不足时，按需使用其可用工具；严禁把 MCP 注册等同于实时可用。该 MCP 不替代证券交易所公告，也不应承载任意代码执行/通用新闻检索。它提供的数据须再经过研究方法验证，不能将 API 输出直接视为投资结论。

研究方法论文或因果识别问题交由 `academic-research`；实际投资研究所需的专业数据、建模与推理保留在 Research，不迁移到其他一级目录。用户要求正式文件时才调用对应交付能力，NotebookLM 与 OIRF 均非此流程的强制前置步骤。
