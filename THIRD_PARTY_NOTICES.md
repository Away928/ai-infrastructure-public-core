# Source attribution and exclusions

This **public core** is a collection of 11 locally authored Skill guidance documents. The bundled license applies only to the included original Skill text and repository scaffolding.

External software and services mentioned in those documents (such as cninfo, REA, FinQ4CN, GitHub, Obsidian, NotebookLM, Google, OpenAI and Anthropic) are **not redistributed, installed or licensed** by this repo. Follow each upstream project's licensing, API terms and independent setup instructions.

The following local skills were deliberately **not** bundled because the release candidate could not substantiate a standalone, appropriately licensed, fully portable distribution:

- `corporate-disclosures`: the original Skill requires a locally installed `cninfo-cli` from its separate upstream source and included obsolete backup material.
- `grill-me` and `grilling`: the original text's provenance/licensing requires additional review.

Entire third-party Plugin/MCP repositories (and caches, installed node_modules, private configuration, archived source) remain outside this distribution. There are no bundled copies of those dependencies.
