# 岗位匹配与职业转向：从 JD Analyzer / Career Changer 提炼

## 解析 JD 时保持维度独立
- 要求性质：必须具备 / 优先考虑 / 软要求 / 表述不明（只用于岗位要求）。
- 要求领域：学历资质 / 专业能力 / 行业知识 / 工作方式与地点 / 可用时间（只用于要求内容）。
- 对每一要求标注：JD 原句、来源/发布日期、可验证对应经历、差距、是否可补齐、重要性依据。
- 将导师 RA 机会拆为研究问题、方法（Python/ML/金融等）、预期产出、可参与时间及材料/推荐要求；不自动套用正式教师招聘标准。
- 关键词仅在事实支持时加入简历；职位检索用 01，机构/导师的研究事实用 02；本模块只做匹配与决策。

## 评估方法
- 区分**硬性不满足**、可补齐的能力缺口、措辞或证据不足，不把“未写在简历”误判为“不会”。
- 输出四列证据矩阵：职位要求｜对应事实证据｜差距/未知｜采取行动。
- 可选按用户明确认可的权重评分，但没有统一客观的 60%、70%、90% 成功率阈值，不能把关键词覆盖率声称为真实录取概率。
- 对招聘文案中的潜在风险（模糊薪酬、职责变化、未说明工作签证等）列成**核实问题**，不凭单个流行词直接判定雇主有问题。
- 职业转型：从旧经历中抽取可迁移的方法（分析、沟通、组织、建模等），标出原情境与新岗位类比；不能把相关能力说成已经有该岗位的直接任职经验。

## 建议输出
资格判断（证据充分/缺口待核/明确不满足）→ 3 项以内匹配优势 → 主要差距与补救建议 → 需要向雇主/导师核实的问题 → 申请优先级（理由而非臆测概率）→ 应交给 career-content-writing 强调的证据。
