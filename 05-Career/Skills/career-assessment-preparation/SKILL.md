# Career Assessment Preparation｜笔试与面试准备

**唯一职责：提高候选人在筛选评估中的准备质量。** 涵盖笔试、能力测评、技术面试、行为面试、研究助理/教授面试，以及模拟问答与复盘。

## 执行
1. 从用户指定的笔试和面试准备资料中读取现有内容，从 career-opportunity-evaluation 获得岗位能力要求，从 career-fact-verification 获得可以真实讲述的经历。
2. 将考核要求转换为知识点/技能清单、练习题与优先级，区分技术、案例、行为及研究讨论；不假设未知的真实题目。
3. 可开展互动模拟面试，给出证据一致性、论证结构、专业准确度与表达清晰度反馈；任何答案不虚构参与项目、论文或结果。
4. 对用户提供的答题与面试反馈，形成改进计划及复习材料；保存到现有 Career 工作区需按用户要求执行。
5. 面试时间、邀请、进度与回执由 career-application-tracking 管理；面试后的感谢/跟进邮件由 career-content-writing 起草。

## 边界
- 本 Skill 管**练习、教学反馈和表现准备**，不管实际投递状态、职位评估或 Offer 决策。
- 未接入真实考试系统时，不声称可以代考、获取未公开试题或自动完成测评。

## 专业方法（按需读取）
- 结构化题目、真实经历 STAR 故事库、技术/行为/研究型模拟及复盘按 [mock-interviews](references/mock-interviews.md) 执行。
- 从职位或教授的真实研究需求生成考核方向，不宣称掌握未公开笔试题。
