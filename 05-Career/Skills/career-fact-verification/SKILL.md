# Career Fact Verification｜职业事实核验

**唯一职责：确定哪些职业事实可以被引用。** 事实的权威来源应由用户明确指定，例如用户自己的经历事实清单、证据索引与对应原始材料；如与项目状态文件不一致，先核对再使用。Career Skill 不创建第二套经历数据库。

## 执行
1. 读取实际 Career 工作区的 README、相关项目状态与经历事实文件，保持历史版本和来源可追溯。
2. 将学历、岗位、时间、项目、个人贡献、方法、指标和成果逐项对应到可核查证据，区分确认事实、用户提供但待核实的表述、建议改写。
3. 对时间倒序、公开边界、保密限制、数量指标和归因做一致性检查；不可从团队成果直接推断个人贡献。
4. 输出可供复用的事实清单：事实、证据路径、状态、允许的表述、待核实点。仅在用户要求时修改权威资料，不覆盖原件。
5. 将核实后的证据交给 career-opportunity-evaluation、career-content-writing 或 career-assessment-preparation 使用。**不负责岗位分析、简历文案、投递管理或排版。**

## 边界
- 事实是否真实：本 Skill 决定；是否适合某岗位：career-opportunity-evaluation 决定。
- 文字如何呈现：career-content-writing 决定；最终版式与 PDF 不归本 Skill。
- 缺失证据时标为待核实，不虚构业绩、论文、日期或数字。

## 专业方法（按需读取）
- 当任务涉及业绩、个人贡献、成果数字、保密披露或原始证据时，先阅读 [verified-metrics](references/verified-metrics.md)，再核实用户的现有证据记录。
- 对不能证明的数字只提出验证问题，禁止用经验估算、来源不明的范围或所谓保守数字补足简历。
