# 申请状态与外部动作：轻量实践

在 ~/Work-Space/Career/Applications/ 的现有资料内维护每次申请，**不创建第二套数据库**。

单条记录建议包含：公司/教授、岗位、职位页面或内部来源、申请渠道、投递稿版本、提交证据（平台确认页/回信/用户明确说明）、提交时间及其时区、当前状态、截止日期、下一步、下次跟进日、注意事项。

状态以可验证事件推进：计划申请→准备中→已提交→等待/测评/面试→Offer/终止；“填写好表单”“生成求职信”“打开网站”都不是已提交。出现多个真实环节时保留阶段历史，而非将两个并列阶段塞成一个模糊状态。

跟进：检查截止日、时区、是否已有回复或用户要求；草拟邮件交给 career-content-writing；向外实际发送、提交、撤回、接受 Offer 均需明确授权。记录回复后再更新状态，绝不把发信成功当作对方已收到或接受。

旧 application-form-filler 的**答案写作**由 content-writing 负责；表单提交和回执验证由本 Skill 负责。
