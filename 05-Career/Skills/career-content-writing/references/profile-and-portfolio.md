# LinkedIn 与作品集内容：原指南提炼

## LinkedIn 的内容结构
- Headline：真实目标方向 + 专业能力 + 可核验的差异点；避免冒用尚未获得的头衔。
- About：研究/业务问题、方法、可验证经历、兴趣方向、希望联系的机会；用自然口吻，不放隐私或保密客户事实。
- Experience/Skills/Featured：与唯一事实母版一致；允许在 LinkedIn 展开更多背景，但不得与正式简历在日期、职称和业绩上冲突。
- 不使用原指南中关于浏览量、推荐算法、发布频率、字符上限等未经及时官方核实的固定数字作为硬规则。

## 研究作品/项目 Case Study
按 Problem → Role → Approach → Decision → Evidence → Outcome/Limits → Learning 组织：
- 问题和约束具体化；解释自己做的哪部分而不是复制团队整体项目。
- AI × Investment 案例写明投资任务、AI 方法、数据与评价设计、本人贡献、已验证结论和局限。
- 图像/论文/数据链接只有在可公开披露且源资料可核实后使用；客户材料、未公开交易或敏感代码不做演示附件。
- 一页简历是摘要，案例页面可更完整；网页/PDF 的技术制作交给 Media / Documents。
- 作品集段落属于求职内容，本 Skill 不负责上传或网页设计。
